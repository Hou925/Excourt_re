# ExCourt Re —— 易场地重构版

本项目是对 **[ShanghaineseImpact/ExCourt](https://github.com/ShanghaineseImpact/ExCourt)** 的系统性重构版本，重点围绕架构优化、关键 Bug 修复、工程规范统一与可维护性提升展开。

## 声明

- 原项目：**ShanghaineseImpact/ExCourt**
- 原作者：**@ShanghaineseImpact**
- 本仓库为基于原项目的**独立重构项目**。

## 项目简介

ExCourt（易场地）是面向学生的羽毛球场地共享预约与管理平台，系统包含：
- 微信小程序前端
- Flask REST API 后端
- 关系型数据库

核心功能包括：
- 用户注册与登录
- 场地交换 / 赠送
- 组队与社交
- 好友管理
- 聊天与图片消息
- 失物招领

## 重构目标

- 修复关键功能与交互问题
- 统一工程规范与开发流程
